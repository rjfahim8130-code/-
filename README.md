# Calculator Vault v2

Age Calculator disguise + Private Vault.

## Features
- Calculator + Age (passcode default 25*52)
- Stories from API
- Dood videos: external browser only
- Local vault: private photos/videos
- No ads

## Setup
1. Copy lib/ and pubspec.yaml into Flutter project
2. flutter pub get
3. AndroidManifest: INTERNET + queries for https VIEW
4. Edit lib/api_config.dart for URL/keys
